# PH Market Prices

A platform for monitoring and comparing foodstuff prices in Port Harcourt markets.

## 📌 Features
- Track prices of rice, beans, garri, etc.
- Compare prices across markets
- View price trends over time

## 📍 Location
Port Harcourt, Nigeria

## 🚀 Project Goal
To help people make better buying decisions and understand market trends.

## 🛠️ Technologies
- HTML
- CSS
- JavaScript (optional later)
